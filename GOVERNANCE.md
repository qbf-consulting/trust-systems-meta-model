# Governance

The Trust Systems Meta-Model (TSMM) is authored and maintained by Sankarshan Mukhopadhyay and stewarded by QBF Consulting LLP. The canonical repository is `qbf-consulting/trust-systems-meta-model`.

TSMM owns canonical trust-system semantics, semantic concept identifiers, model relationships, and semantic projection rules. TIS owns portable machine-readable contract definitions and validation. TGA owns project-local executable governance compositions and patterns. QBF stewardship of TSMM does not collapse those repository authority boundaries or imply ownership of external specifications and third-party contributions.

Changes to canonical TSMM semantics require explicit review, validation, compatibility analysis, and release governance. Historical release artifacts, receipts, commit references, and identifiers remain historical evidence and are not silently rewritten solely because repository ownership or publication location changes.

See `docs/stewardship.md`, `governance/repository-authority.yaml`, `PROJECT-STATUS.yaml`, and `CITATION.cff` for the current authority, status, and citation surfaces.
